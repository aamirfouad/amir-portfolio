AMIR FOUAD PORTFOLIO
======================

1. Open index.html in a browser.
2. Your CV is included as AMIR_FOUAD_CV.pdf.
3. To add your real portrait:
   - create an "assets" folder
   - put your image there as "profile.jpg"
   - in index.html, replace the portrait-placeholder div with:
     <img src="assets/profile.jpg" alt="Amir Fouad" />
4. The design is inspired by the uploaded reference video:
   - warm cream/red palette
   - large editorial typography
   - rounded floating navigation
   - oversized hero image
   - animated marquee
   - project cards
   - scroll reveal animations
   - custom cursor on desktop
5. No framework is required. It uses plain HTML, CSS and JavaScript.
